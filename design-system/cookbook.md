# Cookbook design system

Applies UI UX Pro Max, upstream 616663179c5f9b5e2b3e07cab23ac9cad76378f3 (MIT).
Search: `recipe cookbook content library minimal --design-system` returned an unsuitable children’s Claymorphism direction. It was rejected. The focused `minimalism content library --domain style` match is Minimalism & Swiss Style: readable sans-serif type, whitespace, clear grid, restrained interactions. Palette and Manrope follow the existing ilyamanik.ru identity, as requested by the owner.

- White page; #f5f5f7 panels; #151516 text; #67676c secondary text.
- #c91f29 for accessible red text and selected controls; white text on red.
- Manrope; IBM Plex Mono for small section labels, matching the main site.
- Content max 1280px; 8px spacing rhythm; 16/24/32px rounded blocks.
- Catalog: desktop category rail, compact expandable category list on phones; prominent search and two-column cards. No fabricated food imagery.
- Recipe: single readable heading, clear ingredients panel and numbered instructions; full-width single column on phones; print and large text retained.
- Controls at least 44 CSS px high; visible focus; 16px form inputs; reduced motion; no clipped long Russian labels.
- Verify catalog and detail at 375, 768, 1024, 1440px; search, favorites, ingredient persistence, archive, print, and navigation.
