# Website design preferences

For requests to build a website or improve its UI, apply `ui-ux-pro-max/SKILL.md` and its local search tools. The phrases “UI Pro Max”, “ui ux pro max”, and “сделай оформление по ui pro max скилу” explicitly invoke it. Read the skill before making changes. Use recommendations with judgment and follow the user’s brief and existing site identity.

Keep the main site identity: Manrope, white and pale gray surfaces, dark text, red accent, generous spacing and rounded blocks. For recipes read `design-system/cookbook.md`. Keep recipe source data and original scans unchanged during visual work. Rebuild generated recipe HTML with `python3 recipes/tools/build_site.py` and validate with `python3 recipes/tools/verify.py`.

Use UI UX Pro Max alone for website styling by default. Do not additionally apply frontend-design or gpt-taste unless Ilya explicitly asks: they overlap and may impose conflicting visual rules.
