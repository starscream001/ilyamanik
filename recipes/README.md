# Книга рецептов

Публичный статический сайт для GitHub Pages: https://ilyamanik.ru/recipes/

## Содержание

- 73 рецептурные записи, включая варианты техкарт и неполные рукописные рецепты.
- 15 групп кухонных заметок.
- Все 94 исходные страницы (24 + 24 + 24 + 22), с привязкой к материалам.
- Четыре оригинальных PDF без изменений, SHA-256 в `data/source-manifest.json`.
- Документ Word и Markdown, единая структурированная база JSON.

## Источник истины и сборка

Редактируйте `data/recipes.json`: `recipes` — рецепты, `notes` — заметки, `pages` — реестр исходных страниц. Пары чисел в количествах — брутто/нетто. Не заменяйте неясные рукописные цифры предположениями; добавляйте уточнение в `issues`.

Из корня репозитория:

```sh
python3 recipes/tools/build_doc.py  # нужен python-docx
python3 recipes/tools/build_site.py
python3 recipes/tools/verify.py
python3 -m http.server 8765
```

Откройте http://localhost:8765/recipes/. Сборщик сайта использует только стандартную библиотеку Python. Сайт не требует npm, внешних шрифтов, API, серверной базы или ключей. Сгенерированный HTML хранится в Git и читается без JavaScript. JavaScript добавляет поиск, локальное избранное, отметки, крупный текст и печать. Избранное и отметки хранятся в браузере, без синхронизации устройств.

Для нового DOCX после содержательных правок требуется повторная визуальная проверка рендера всех страниц. Текущая версия проверена рендером bundled LibreOffice.

## Исходники и точность

`originals/` — исходные PDF, `scans/` — повёрнутые превью для чтения, `ocr/` — **черновое автоматическое** распознавание Apple Vision с координатами и уверенностью. OCR не является проверенной расшифровкой, особенно для рукописей и повёрнутых листов. `tools/ocr.swift` позволяет повторить первоначальное распознавание на macOS.

Печатные повторения объединены, отличающиеся варианты сохранены. Карты № 7 и № 9 объединены в одну запись с указанием различий. Карта № 22 разделена на три консистенции каши. Карты № 16, 17 и 26 в приложенных сканах отсутствуют; они не дополнены из других источников.

Выходы и противоречия оригиналов не исправлялись арифметически. Исторические ценовые и бытовые пометки полностью сохранены на сканах; полная проверенная текстовая расшифровка всех цен ещё не выполнена. Часть разборчивых итогов и пищевая ценность салатов приведены в примечаниях. Неразборчивые и обрезанные рукописные фразы требуют сверки владельцем.

## Публикация и поддомен

Эта книга добавлена в существующий репозиторий `starscream001/ilyamanik` отдельным каталогом `recipes/`. Корневой CNAME `ilyamanik.ru` и остальные сайты не изменены. При публикации GitHub Pages из корня ветки main книга появляется по `/recipes/`.

Поддомен — отдельный следующий шаг: выбрать точное имя, настроить DNS и хостинг для этого имени. Второй CNAME внутри `recipes/` не создаёт отдельный GitHub Pages сайт. Для самостоятельного поддомена удобно использовать отдельный Pages-репозиторий и изменить абсолютный префикс `/recipes/` на `/` в сборщике, CSS/JS не зависят от него. Не переназначайте корневой CNAME существующего сайта ради книги.
